# Roadmap

## v0.1 — deterministic kernel

- Scenario and proposal contracts
- Weighted multi-dimensional scoring
- Hard mutation-boundary gate
- Markdown/JSON reports and integrity receipts
- Azure networking, Kubernetes FinOps and BGP scenario seeds

## v0.2 — infrastructure parsers

- Terraform/OpenTofu plan adapter
- Bicep/ARM validation adapter
- Kubernetes server-side dry-run adapter
- Ansible check-mode adapter
- OPA/Rego policy pack

## v0.3 — agent interoperability

- MCP benchmark server
- OpenTelemetry agent/tool-call traces
- LangGraph, CrewAI, Microsoft Agent Framework and NVIDIA NIM adapters
- Cost, latency and token normalization

## v1.0 — public benchmark

- Thirty reviewed scenarios
- Reproducible OCI scenario packs
- Signed provenance and evidence custody
- Public results format and submission validation
- Hosted leaderboard backed only by reproducible runs
